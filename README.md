 API Testing – Banking Flow (Postman)

 Presentation:
This project is an API testing suite for a banking system in Postman using JSONPlaceholder as a mock rest API.  
It covers GET, POST, PUT and PATCH methods, including automated response validation with JavaScript.


Tools Used:
- Postman
- JavaScript (test scripts)
- REST API


 Test Coverage:

 GET Accounts:
- Validate status code 200
- Verify response is an array

 POST Create Account:
- Validate status code 201
- Validate response schema
- Verify created data

PUT Update Account:
- Validate full update of fields
- Verify response consistency

 PATCH Update Balance:
- Validate partial update
- Verify updated balance


 What I did:
- I worked with REST API (CRUD operations)
- I validated API responses
- I wrote test scripts in Postman
- I verified response schema and data consistency
